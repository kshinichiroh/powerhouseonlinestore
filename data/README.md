# data/

チーム単位のデータのみを置く。**選手個人のデータは置かない。**

| ファイル | 内容 | 出典 |
| --- | --- | --- |
| `team_index.csv` | 掲載順・男女・整理番号・チーム名・選手数（125チーム） | `JWC2026_チーム紹介メンバー表_全体検証版` |
| `material_status.csv` | チームごとの集合写真／ロゴ／広告区分の状態 | `JWC2026 写真名簿 進行管理台帳`（代表者名・連絡先は除外済み） |
| `bracket_men.csv` / `bracket_women.csv` | 組合せ番号とチーム名 | 公式最新版トーナメント表PDF（2026-09-14） |

## ここに置かないもの

`members_master.csv`（選手1,781名の氏名・学年・身長・学校名）は `.gitignore` 済み。
正本はJBA帳票（2026年度チームメンバー一覧表）とGoogle Drive共有フォルダのみで管理する。

`tools/build_xlsx.py` を実行するときは、Driveから取得した `members_master.csv` を
カレントディレクトリに置いてから実行する。列は
`掲載順,男女,整理番号,チーム名,No.,名前,学年,身長,学校名`（1行1名）。
