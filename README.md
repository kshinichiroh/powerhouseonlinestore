# JWC2026 兵庫県予選大会 パンフレット制作ルール

Jr.ウインターカップ2026-2027（2026年度第7回全国U15バスケットボール選手権）
兵庫県予選大会の大会パンフレット制作に関する、
一般財団法人兵庫県バスケットボール協会U15部会 広報部 ⇔ ダイコロ株式会社 間の
**確定済み運用ルール**と、その根拠データを置くリポジトリです。

同じ確認が何度も往復しないよう、一度確定した判断はすべてここに記録します。

## 構成

| パス | 内容 |
| --- | --- |
| `docs/jwc2026/00_パンフレット制作ルール.md` | 確定済みの制作ルール（これが正） |
| `docs/jwc2026/01_素材ステータスと定型回答.md` | 「データ未着」照会への回答根拠と定型文 |
| `docs/jwc2026/02_トーナメント表の読み方.md` | 試合コード（日付＋会場＋コート＋時刻）の凡例 |
| `docs/jwc2026/03_やり取りの記録.md` | いつ・何を確定したかの履歴 |
| `data/` | チーム単位の素材ステータス・組合せデータ（個人情報は含めない） |
| `tools/` | 入稿用Excel（トーナメント表データ版・メンバー表チーム別シート版）の生成スクリプト |
| `.claude/skills/jwc-pamphlet/` | 上記ルールを自動適用するためのスキル |

## 個人情報の取り扱い

選手名簿（氏名・学年・身長・学校名／1,781名）は **このリポジトリには置きません**。
正本はJBA帳票とGoogle Drive共有フォルダのみで管理し、`tools/` のスクリプトは
実行時にDriveから取得したCSVを読み込みます（`.gitignore` 参照）。
電話番号・メールアドレス・住所・JBAメンバーIDは入稿データにも含めません。
