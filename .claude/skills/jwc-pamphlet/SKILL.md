# JWC パンフレット制作の対応

## 最初に読むもの

必ず以下を読んでから回答・作業する。ここに書かれていることを推測で上書きしない。

1. `docs/jwc2026/00_パンフレット制作ルール.md` — 確定済みの制作ルール（これが正）
2. `docs/jwc2026/05_正本データの所在.md` — どのデータの正本がどこにあるか
3. `docs/jwc2026/01_素材ステータスと定型回答.md` — 「データ未着」照会への回答手順と定型文
4. `docs/jwc2026/02_トーナメント表の読み方.md` — 試合コードの凡例
5. `docs/jwc2026/03_やり取りの記録.md` — いつ何を確定したか

## 基本方針

**同じ照会を往復させない。** 相手からの質問には、根拠（台帳の行・便番号・受付日）を添えて
一度で確定的に答える。「確認します」で止めず、台帳を引いて結論まで書く。

## 「データが未着です」と言われたとき

1. 早合点して謝らない。まず台帳を引く。実際に未提出であることはほとんどない。
2. 確認順は `01_素材ステータスと定型回答.md` の手順に従う。
3. 「広告不要」「写真なし」「チーム名のみ」は **確定状態であり未提出ではない**。そう明言する。
4. 似た名称の別チームの取り違えを疑う（WEST RIVER と RIVER WEST など。ルール9を参照）。
5. 回答には 受付日・入稿便・格納フォルダ を必ず書く。

## 絶対に変えない判断

- 誌面のチーム名は **JBA帳票の登録名**。トーナメント表PDFやフォルダ名の表記ではない。
- チーム紹介文は **入れない**（写真／ロゴ・チーム名・名簿のみ）。
- **スタッフは掲載する。** HC／AC／チーム責任者／トレーナー／チームスタッフ／帯同審判①②／帯同MC。
  出所は大会エントリーシート。「掲載しない」と答えてはならない（2026-09-15に誤答しかけた事故）。
  個人情報（電話番号・メール・住所・JBAメンバーID）を入稿データから外すこととは別の話。
- 選手名簿は **No.／名前／学年／身長／学校名** の5項目・この順序。
- 素材受付は **第19便（2026-09-11）で終了**。以降の追加・差し替えは受け付けない。
- 共通広告は **1点のみ配置**。チームごとに重複配置しない。

## 前年度の誌面で裏を取る（重要）

「前回はどうだったか」が論点になったら、**必ず2025年度の完成誌面スキャンを開いて確認する。**
Drive の「2025パンフレット資料」フォルダ（`1q2_Ue95fJ8q2EkwDVvwK8QdgqL_XqtGm`）に
ページ単位のJPEGがあり、チーム紹介ページはおおむね 015〜038。
`read_file_content` で画像を読めば記載項目を確認できる。

- 台帳や作業メモの記述を根拠に「前年度はこうだった」と断定しない。**誌面が唯一の証拠。**
- 誌面に載る／載らないの判断を推測で書かない。掲載漏れは刷り直しになる。
- 実際に2026-09-15、検証シートの「スタッフ情報は収録していない」という一文だけを根拠に
  「スタッフは掲載しない方針」と誤って書いた。誌面を見れば全チームに載っていた。

## 呼び名を勝手に増やさない

「エントリーシート」「参加申込書」「大会申込書」は **すべて同じ書類**（チームが記入するExcel）。
呼び分けたり、別の書類として扱ったりしない。2026-09-15にこれを別物として説明し、
岸さんを混乱させた。書類の同一性が怪しいと思ったら、まず実物のファイル名を確認する。

## 個人情報

- 選手名簿（氏名・学年・身長・学校名）は **このリポジトリに置かない**。正本はJBA帳票とDrive共有フォルダ。
- 電話番号・メールアドレス・住所・JBAメンバーIDは **入稿データにも含めない**。
- 素材台帳には代表者名・連絡先が入っているので、抽出するときは
  チーム名・男女・写真／ロゴ／広告の有無のみに絞る（`tools/build_xlsx.py` の実装を参照）。

## 入稿用Excelを作るとき

`tools/build_xlsx.py` を使う。生成物は2点。

- `JWC2026_トーナメント表_データ版_YYYYMMDD.xlsx`
  大会概要／日程・会場／会場コード凡例／試合コード一覧／男女の組合せ／表記ゆれ／制作ルール
- `JWC2026_チーム紹介メンバー表_チーム別シート版_YYYYMMDD.xlsx`
  目次／全体データ（1行1名）／**チーム別シート**（デザイナー様の要望。`M{番号}_` `W{番号}_`）／掲載対象外／制作ルール

必ず守ること:

- 両ファイルに `99_制作ルール` シートを入れる。ルールを誌面側にも常駐させるため。
- チーム別シートは必ず作る。デザイナー様はチーム単位で作業する。
- 数が合っているか検算してから渡す（チーム数・選手数を `data/` の集計と突き合わせる）。
- **手で書き写した値は必ず出典と機械照合する。** 2026-09-15、公式PDFから書き写した試合コード133件に
  1件の誤り（`25グD15:30` → 正 `25グB15:30`）があった。日付と会場の整合チェックでは
  コート記号の取り違えを検出できない。照合は出典そのものと1対1で取ること。
- 共有はDriveの共有フォルダ。メール添付はしない（版の取り違え防止）。

## 返信文の型

宛名 → 用件の一覧 → 項目ごとに「結論 → 根拠（受付日・入稿便・フォルダ）→ 誌面での扱い」
→ 今後のためのルール参照先、の順で書く。相手が再質問しなくて済む粒度にする。

## 新しい判断が確定したら

`docs/jwc2026/00_パンフレット制作ルール.md` と `03_やり取りの記録.md` に追記し、
入稿用Excelの `99_制作ルール` シートにも反映してからコミットする。
記録しないと同じ照会がまた来る。
