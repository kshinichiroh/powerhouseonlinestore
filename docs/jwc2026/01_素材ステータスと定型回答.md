# 素材ステータスの見方と、照会への定型回答

最終更新: 2026-09-15

「◯◯のデータが未着です」という照会は毎回発生する。
その多くは **提出済み** か、**提出しないことが確定している** かのどちらかで、
実際に未提出というケースはほぼない。以下の順で確認し、定型文で回答する。

## 確認の順番

1. 台帳 `JWC2026_入稿一覧・差替履歴`（Drive `00_入稿一覧・差替履歴`）の「チーム別照合」タブ
2. 台帳 `JWC2026 写真名簿 進行管理台帳` の 写真URL／ロゴURL／広告区分／状態
3. 入稿用Excel `JWC2026_チーム紹介メンバー表_チーム別シート版` の「00_目次」
4. 同Excel「98_掲載対象外」（棄権・参加対象外でないかの確認）

## ステータスの意味

| 表示 | 意味 | 誌面での扱い |
| --- | --- | --- |
| 広告不要 | 広告を出さないことが確定 | 広告枠を作らない。未提出ではない |
| 写真なし | 集合写真を提出しないことが確定 | ロゴがあればロゴ、なければチーム名と名簿のみ |
| チーム名のみ | 写真・ロゴ・広告のいずれも出さないことが確定 | チーム名と名簿のみ |
| おまかせ | 広告デザインを協会側に一任 | 協会側で完成広告を作成して入稿済み |
| 版下提出 / 版下提出済 | チームから完成版下を受領済み | そのまま配置 |
| 完成広告差替済み | 協会側で規定寸法の完成PDFに差し替え済み | 新版のみ使用 |

## スタッフの扱い（誤答に注意）

スタッフは **掲載する**。「掲載しない方針」と答えてはならない（2026-09-15に一度誤答しかけた）。
根拠は `00_パンフレット制作ルール.md` の第4項（2025年度の完成誌面スキャンで実地確認済み）。

- 掲載項目: HC／AC／チーム責任者／トレーナー／チームスタッフ／帯同審判①②／帯同MC
- 出所: 大会エントリーシート（JBA帳票には入っていない）
- 個人情報（電話番号・メール・住所・JBAメンバーID）を入稿データから外すこととは別の話。

## 定型回答

> ご指摘の件、当方の台帳で確認いたしました。いずれも未提出ではございません。
> 「広告不要」「写真なし」「チーム名のみ」はいずれも、そのチームがその素材を
> 提出しないことが確定している状態です。素材の受付は第19便（9月11日）で
> 終了しておりますので、追加提出は発生いたしません。
> 各チームの状態は入稿用Excelの「00_目次」および台帳「チーム別照合」タブに
> 記載しておりますので、そちらでご確認いただけます。
