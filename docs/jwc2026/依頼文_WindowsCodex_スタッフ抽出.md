## 抽出する項目

各チームについて、PDFに記載のある役職だけを抽出する。記載のない役職は行を作らない。

- ヘッドコーチ
- アシスタントコーチ（複数名のことがある。記載順を保持）
- チーム責任者
- マネージャー
- トレーナー
- チームスタッフ（複数名のことがある。記載順を保持）
- 帯同審判①／帯同審判②

**抽出しないもの（誌面に載せない／入稿データに含めない）**

- JBA ID No.

- 代表者の携帯電話番号・PCアドレス・住所

## 作業

### 手順1　抽出して中間データを作る

`data/staff_master.csv` として書き出す。**1行1名。**

```
男女,プログラム番号,チーム名,役職,表示順,氏名,出典PDF,出典ページ
```

- `プログラム番号` は前作業で確定した番号（`data/number_crossref.csv` と `data/program_numbers.csv` 参照）。
- `役職` は上記9種のいずれか。アシスタントコーチ・チームスタッフが複数いる場合は `表示順` で区別する。
- `出典PDF` `出典ページ` は目視確認のために必ず入れる。

### 手順2　氏名をJBA正本と照合する（最重要）

**誌面の氏名はJBA正本（入力B）の印字を正とする。** 選手の氏名と同じ扱い。
エントリーシートPDFはスキャン画像で、OCRの氏名誤読が実際に確認されている。

| OCR結果 | 正しい表記 |
| --- | --- |
| 三上證人 | 三上慶人 |
| 酒店 奎太 | 酒居 奎太 |
| 岩標亮平 | 岩橋亮平 |
| 斉藤 真实 | 斉藤 真実 |

照合できる役職とできない役職があるので、分けて扱う。

| 役職 | JBA正本での対応 | 扱い |
| --- | --- | --- |
| ヘッドコーチ | コーチ欄・構成員区分「コーチ」 | **JBA正本の氏名を採用** |
| アシスタントコーチ | コーチ欄・構成員区分「アシスタントコーチ」 | **JBA正本の氏名を採用** |
| チーム責任者 | 責任者欄 | **JBA正本の氏名を採用** |
| 帯同審判①② | 帯同審判欄 | **JBA正本の氏名を採用** |
| マネージャー | 対応なしの見込み | エントリーシートのみ。`要確認` を立てる |
| トレーナー | 対応なしの見込み | 同上 |
| チームスタッフ | 対応なしの見込み | 同上 |
| 帯同MC | 対応なしの見込み | 同上 |

手順:

0. **Bに125チーム全部が含まれているかを先に確認する。** ページ数は1チーム2ページとは限らない
   （報告されたページ数 男子1-40=80／男子41-77=68／女子=106 は、2ページ×チーム数と一致しない）。
   欠けているチームがあれば止めて報告する。棄権2チームは含まれていてもよい。
1. JBA正本PDFから、チームごとに 責任者・コーチ・帯同審判 の氏名を抽出する
   （**メンバーID・電話番号・ライセンス・生年月日は抽出しない**）。
   画像PDFなのでOCRになる。**AのOCRとは独立に実施する**（Aの結果を見ながら読まない）。
2. エントリーシートPDFから抽出した役職の割り当てと突き合わせる。
3. 氏名が一致すれば **JBA正本の表記を採用**する。
4. **一致しない場合は上書きせず、両方を残して `要確認` を立てる。** どちらが正しいか推測しない。
   差異候補は、該当ページを画像としてレンダリングし、**原本画像で目視確認**する。
   目視で確定できたものは `照合結果` を `原本画像で確認` とし、確定した表記を採用する。
   目視でも読み取れないものは `要確認` のまま残す。
5. JBA正本に対応欄のない役職（マネージャー／トレーナー／チームスタッフ／帯同MC）は
   エントリーシートの表記を採用し、全件 `要確認` を立てる。判読に迷ったものは特に明示する。

`data/staff_master.csv` に次の列を追加する。

```
JBA正本での氏名,照合結果,要確認
```

`照合結果` の許容値は次の7つ。**これ以外の値を使わない。**

| 値 | 意味 | 要確認 |
| --- | --- | --- |
| `一致` | AとBのOCR結果が一致 | 不要 |
| `原本画像で確認` | 差異候補を原本画像で目視し、表記を確定した | 不要 |
| `字体差のためJBA表記を採用` | 旧字体↔新字体の違いのみ。手順2-Aで確定 | 不要 |
| `JBA正本内で確認（役職は別区分）` | 役職は違うが同一チーム内にBの登録あり。手順2-Bで確定 | 不要 |
| `不一致` | 原本画像で確認してもなお確定できない | **要** |
| `JBA正本に該当者なし` | チーム単位で照合してもBに見当たらない | **要** |
| `JBA正本に対応欄なし` | チーム単位で照合してもBに見当たらず、役職欄も存在しない | **要** |

### 手順2-A　字体差を確定させる

旧字体・異体字の違いだけのものは、**JBA正本（B）の表記を採用して確定**する。要確認にしない。
選手の氏名と同じ扱い（検証シート「氏名10件を正本表記へ修正」）。

対象とする対応の例: 眞/真 髙/高 濱/浜 濵/浜 邊/辺 邉/辺 齋/斎 齊/斉 嶋/島 﨑/崎 嵜/崎
德/徳 瀨/瀬 澤/沢 栁/柳 冨/富 渕/淵 曻/昇 など、**確立した旧字体↔新字体の対応に限る。**

**似ているだけの別字は対象外。要確認のまま残す。**
昴/昂、吾/五、慎/真、幸/辛、未/末、土/士、己/已/巳 など。
判断がつかないものは対象外にする。**広げない。**

使用した対応表は全件報告すること。

### 手順2-B　役職を問わずチーム単位で照合する

役職どうしの突き合わせでは、大会でマネージャーやトレーナーを務める方が
JBAには「コーチ」として登録されている場合に照合できない。

`JBA正本に対応欄なし` `JBA正本に該当者なし` および未確定の `不一致` について、
**そのチームのBページ全体（責任者・コーチ・帯同審判のすべてのセクション）に
同一氏名があるか**を照合する。

- 見つかれば `JBA正本内で確認（役職は別区分）` とし、**B表記を採用**する。
  Bでの登録区分も `JBA正本での役職` 列に記録する。
- 見つからなければ、そのまま `JBA正本に該当者なし` / `JBA正本に対応欄なし` を維持する。

### 手順2-C　残りを全件、原本画像で確認する

`不一致` として残っているものは、**全件、該当ページを画像としてレンダリングして目視確認する。**

- 確定できたものは `原本画像で確認` とし、確定した表記を採用する。
- **画像を見てもなお読み取れないものだけ** `不一致` のまま残す。
- 報告では「画像で確定できた件数」と「画像を見ても確定できなかった件数」を**必ず分けて書く。**
  「画像を確認していないもの」を残さない。

### 手順2-D　絞り込みの結果を報告して止まる

**ここで必ず停止し、承認を待つ。** 手順3以降へ進まない。報告に含めるもの:

- 手順2-A／2-B／2-C の各段階で、要確認が何件から何件に減ったか
- 最終的に岸さんに目視をお願いする件数と、その内訳（`不一致` / `該当者なし` / `対応欄なし`）
- 手順2-Aで使用した字体の対応表（全件）
- **チーム別のスタッフ行数の分布。** 特に次を明示する。
  - スタッフが0行のチームがあるか（あれば一覧）
  - ヘッドコーチが取れていないチームがあるか（あれば一覧）
  - 1チームあたりの行数の最小・最大
- 役職別の人数（ヘッドコーチ何名、アシスタントコーチ何名 …）

## 禁止事項

- **推測で埋めない。** 読めない氏名は `要確認` として残し、確定させない。
- **外部への送信・共有は一切行わない。** Google Driveの共有フォルダへの格納も、
  ダイコロ様へのメールも、**岸さんの明示承認を得るまで行わない。**
  共有フォルダへ置く行為は、通知前でも「入稿」とみなす。
- **個人情報をリポジトリにコミットしない。** `data/staff_master.csv` と生成xlsxは `.gitignore` に追加する。
  コミットしてよいのは `tools/build_xlsx.py` の改修と、件数・集計のみ。
- JBA ID（メンバーID）・保有ライセンス・連絡先・生年月日は抽出もしない。
  JBA正本PDFには電話番号が含まれているので、特に注意すること。
