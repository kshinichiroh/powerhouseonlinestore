## 背景

このまま進めると全125チームのスタッフが誌面から消える。

スタッフの氏名は、すでに受領済みのエントリーシート（＝参加申込書＝大会申込書）PDFに記載がある。
**チームへの再依頼は不要。** このPDFから抽出する。

## 抽出する項目

各チームについて、PDFに記載のある役職だけを抽出する。記載のない役職は行を作らない。

- ヘッドコーチ
- アシスタントコーチ（複数名のことがある。記載順を保持）
- チーム責任者
- マネージャー
- トレーナー
- チームスタッフ（複数名のことがある。記載順を保持）
- 帯同審判①／帯同審判②
- 帯同MC

**抽出しないもの（誌面に載せない／入稿データに含めない）**

- JBA ID No.
- 保有ライセンス（JBA公認C級 等）
- 代表者の携帯電話番号・PCアドレス・住所
- 活動地区

## 作業

### 手順1　抽出して中間データを作る

`data/staff_master.csv` として書き出す。**1行1名。**

```
男女,プログラム番号,チーム名,役職,表示順,氏名,出典PDF,出典ページ
```

- `プログラム番号` は前作業で確定した番号（`data/number_crossref.csv` と `data/program_numbers.csv` 参照）。
- `役職` は上記9種のいずれか。アシスタントコーチ・チームスタッフが複数いる場合は `表示順` で区別する。
- `出典PDF` `出典ページ` は目視確認のために必ず入れる。

### 手順2　氏名の精度を担保する（最重要）

**このPDFはスキャン画像で、OCRの氏名誤読が多い。** 実際に次のような誤読が確認されている。

| OCR結果 | 正しい表記 |
| --- | --- |
| 三上證人 | 三上慶人 |
| 酒店 奎太 | 酒居 奎太 |
| 岩標亮平 | 岩橋亮平 |
| 斉藤 真实 | 斉藤 真実 |

**誤字のまま印刷されると刷り直しになる。** 次をすべて行うこと。

1. PDFにテキスト層があるか確認し、**あればテキスト層を優先**する。OCRは最後の手段。
2. 各ページを画像としてレンダリングし、抽出結果と1件ずつ突き合わせる。
3. 判読に迷った文字・低信頼の氏名は、`data/staff_master.csv` に列 `要確認` を追加して `要` と記す。
   **推測で確定しない。**
4. 他の資料に同一人物が出ている場合は照合に使う（例: Drive `JWC2026 写真名簿 進行管理台帳` の代表者名、
   `JWC2026_入稿一覧・差替履歴`）。一致しない場合は `要確認` とする。

### 手順3　件数を検算する

| 項目 | 期待値 |
| --- | --- |
| 対象チーム数 | 125（男子75・女子50） |
| スタッフが1名も取れなかったチーム | 0件（あれば一覧で報告） |
| 棄権チーム（男子13 BAMBOO Shoot U15／男子75 A.C.T. BASKETBALL CLUB 2026） | 抽出対象外 |

役職別の人数も集計して報告する（ヘッドコーチ何名、帯同審判①何名 …）。
ヘッドコーチが取れないチームがあれば、原本のどこに何と書いてあるかを添えて報告する。

### 手順4　入稿用Excelへ反映する

`tools/build_xlsx.py` を改修し、`JWC2026_チーム紹介メンバー表_チーム別シート版` を再生成する。

- 各チームシートの既存の「チームスタッフ」欄（空欄9行の固定表）を、**実データの行に置き換える**。
  記載のない役職の行は作らない。複数名の役職は名前を並べる。
- 並び順は昨年度の誌面に合わせる。
  ヘッドコーチ → アシスタントコーチ → チーム責任者 → マネージャー → トレーナー →
  チームスタッフ → 帯同審判① → 帯同審判② → 帯同MC
- 「00_目次」に **スタッフ人数** の列を追加する。
- シート冒頭の注記「※スタッフは大会エントリーシートから後日差し込みます（2026-09-15時点で未収録）」を削除する。
- `99_制作ルール` の第4項を「スタッフは掲載する（収録済み）」の記述に更新する。

### 手順5　目視確認用の一覧を作る

岸さんが短時間で確認できるものを1点作る。

- `JWC2026_スタッフ確認用一覧_20260915.xlsx`
- 1チーム1行。プログラム番号／男女／チーム名／各役職の氏名／出典ページ／`要確認` の有無。
- `要確認` のある行は先頭にまとめる。

## 禁止事項

- **推測で埋めない。** 読めない氏名は `要確認` として残し、確定させない。
- **外部への送信・共有は一切行わない。** Google Driveの共有フォルダへの格納も、
  ダイコロ様へのメールも、**岸さんの明示承認を得るまで行わない。**
  共有フォルダへ置く行為は、通知前でも「入稿」とみなす。
- **個人情報をリポジトリにコミットしない。** `data/staff_master.csv` と生成xlsxは `.gitignore` に追加する。
  コミットしてよいのは `tools/build_xlsx.py` の改修と、件数・集計のみ。
- JBA ID・保有ライセンス・連絡先は抽出もしない。
