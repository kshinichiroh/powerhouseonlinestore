# 「パンフレット購入申込の案内が届かない」と言われたときの手順

最終更新: 2026-09-15

一斉案内を出すと必ず数件出る照会。**推測で謝る前に、送信記録を引く。**
多くは送信済みで、迷惑メールフォルダに入っている。

## 確認の順番

1. **送信済みか。** Gmailの送信済みを `subject:パンフレット 購入 申込` とチーム名で検索する。
   件名は `【{チーム名}／{男女}】JWC2026 パンフレット購入 申込のご案内`。
2. **宛先アドレスは照会で聞いたものと一致するか。** 違っていればそれが原因。
3. **バウンスが出ていないか。** `from:mailer-daemon OR subject:"Delivery Status Notification" in:anywhere` で検索。
   Gmailはバウンス通知を自動でゴミ箱に入れることがあるので、**`in:anywhere` を必ず付ける。**
4. **すでに申込済みでないか。** `subject:パンフレット購入申込 受付` とチーム名で検索。

## 判断

| 状況 | 原因 | 対応 |
| --- | --- | --- |
| 送信済み・バウンスなし・未申込 | **迷惑メールフォルダの可能性が高い** | 迷惑メールの確認を依頼したうえで再送する |
| 送信済み・バウンスあり | アドレスが誤り／存在しない | 正しいアドレスを確認して再送する |
| 送信記録がない | 案内の対象から漏れている | すぐ送る。他にも漏れがないか一斉送信のリストと出場チームを突き合わせる |
| すでに申込済み | 本人以外が申し込んだ可能性 | 受付番号と購入担当者名を伝えて確認してもらう |

Gmailから yahoo.co.jp・ezweb.ne.jp 等へ送る、URLと英数字コードを含む定型文は
迷惑メール判定されやすい。**バウンスが出ていないなら配信自体は成功している。**

## 申込コードの扱い

- コードは**チーム専用**。他チームへ転送・共有しない。
- 再送しても同じコードでよい。コード自体は失効しない。
- 同じコードで再送信されると、前回内容への追加ではなく**全内容が置き換わる**。
- 紛失・漏えいの可能性があるときは再発行する。
