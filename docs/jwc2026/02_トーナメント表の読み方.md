トーナメント表の各試合には、開催日・会場・コート・開始時刻が
**1つの記号にまとめて**印字されている。「記載がない」ように見えるのはこの記号を
読み解けていないためなので、照会が来たら本ページを案内する。

## 記号の構成

```
18 相 A 15:00
│  │  │  └─ 開始時刻
│  │  └──── コート（A面／B面／C面／D面）
│  └─────── 会場記号
└────────── 開催日（日付の数字）
```

例:
- `18相A15:00` = 10月18日(日)・相生市民体育館・A面・15:00開始
- `25グC12:30` = 10月25日(日)・グリーンアリーナ神戸・C面・12:30開始
- `15総A11:00` = 11月15日(日)・兵庫県立総合体育館・A面・11:00開始
