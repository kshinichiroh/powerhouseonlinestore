## スタッフ

**出典が2つある。役割が違うので混ぜないこと。**

| | 何の正本か | 収録範囲 |
| --- | --- | --- |
| エントリーシートPDF | **役職の割り当て**（誰がHCで誰が帯同MCか） | HC／AC／チーム責任者／マネージャー／トレーナー／チームスタッフ／帯同審判①②／帯同MC |
| TeamJBAチームメンバー一覧表PDF | **氏名の表記** | 責任者／コーチ／アシスタントコーチ／帯同審判 |

TeamJBAの書式（2022年度の実物 `JBAチームメンバー一覧表(北イーグルス）.pdf` で確認）:
責任者・競技者・コーチ・帯同審判の4セクションがあり、コーチ欄の「構成員区分」で
コーチ／アシスタントコーチを区別する。

**2026年度の受領物にテキスト層はない（全ページ画像）。** 喜録先生がTeamJBAの出力を
紙に印刷してスキャンしたものだから（「何度も紙が詰まったので、上下バラバラです」）。
Driveにある2022年度のファイルはTeamJBAからの直接ダウンロード版で、こちらとは別物。
**綺麗に読めたことをテキスト層の証拠にしない。**

- **誌面の氏名はJBA正本を正とする**（選手の氏名と同じ扱い）。
- マネージャー／トレーナー／チームスタッフ／帯同MC はJBA正本に対応欄がない見込みで、
  エントリーシートのみが出典になる。目視確認が要る。
- JBA正本PDFには電話番号・メンバーID・ライセンス・生年月日が含まれる。**抽出しない。**
