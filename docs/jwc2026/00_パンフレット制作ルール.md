- 過去に通知済みの訂正例: teamDENY→team DENY、BAY CROWN JUNIOR→BAYCROWN JUNIOR、
  North Wave→NorthWave、WESTRIVER→WEST RIVER。

## 2. チーム紹介ページの構成

- **チーム紹介文は入れない。** 掲載するのは 集合写真（またはロゴ）・チーム名・選手名簿 のみ。
- 各チームの広告枠内にある文言は、その広告デザインの一部としてそのまま掲載する。

## 3. 集合写真がないチーム

- 集合写真の提出は **任意**。写真がないチームは「未提出」ではなく **「写真なしで確定」**。
- ロゴがある場合はロゴを使用。ロゴもない場合はチーム名と名簿のみで組む。
- 素材受付は終了しているため、追加提出は発生しない。催促・再確認は不要。

## 4. スタッフ情報

- スタッフ（ヘッドコーチ・アシスタントコーチ・チーム責任者・マネージャー・トレーナー・帯同審判等）は
  **誌面に掲載しない**。2025年度と同じく選手のみを掲載する。
- 個人情報保護のため、電話番号・メールアドレス・住所・JBAメンバーIDは入稿データにも含めない。

## 5. 選手名簿の項目と順序

- **No.／名前／学年／身長／学校名** の5項目・この順序で統一（2025年度パンフレットに準拠）。
- 背番号の飛び番は原票どおり保持する。
- 大会申込書正本に「小5」「小6」と印字された選手は、その文字列のまま掲載する。

## 6. 素材の受付終了

- チーム素材の受付は **2026-09-11の第19便（最終便）をもって終了**。以降の追加・差し替えは受け付けない。
- 旧版が過去便のフォルダに残っていても、差替指示のあるものは新版のみを使用する。
  - NorthWave: 9月5日「最終確定一括」の男子1/8版 → 男女共通1/4版
  - Wild Wolves: 第13便の男子1/8版 → 男女共通1/4版
  - All BLUE / ALL BLUE GAO: 低解像度JPEG → 2026-09-14差替の1/4（174×62mm）PDF
  - DunkGO Club / HDC Academy Cranes: 規定外寸法の版下 → 2026-09-14差替の1/4（174×62mm）PDF

## 7. 広告

- 仕上寸法: 1/2 = 174×128mm / 1/4 = 174×62mm / 1/8 = 82×62mm（いずれも塗り足しなし）。
- 複数チーム共通の広告は **1点のみ配置し、チームごとに重複配置しない**。
  共通広告に含まれるチーム数は台帳「チーム別照合」タブに記載。
- センターサークル関連4チームの共同広告は先頭に配置しない（末尾または先頭以外であれば可）。
- 「おまかせ」指定のチームは、協会側で完成広告（グレースケール）を作成して入稿する。

## 8. 「データ未着」の照会が来たときの手順

1. 台帳「JWC2026_入稿一覧・差替履歴」の **「チーム別照合」タブ** を確認する。
2. 入稿用Excel「00_目次」「05_男子_組合せ」「06_女子_組合せ」の素材ステータス列を確認する。
3. 以下はいずれも **確定状態であり、未提出ではない**。
   - 「広告不要」… そのチームは広告を出さないことが確定している
   - 「写真なし」… 集合写真を提出しないことが確定している
   - 「チーム名のみ」… 写真・ロゴ・広告のいずれも出さないことが確定している
4. 該当チームが棄権・掲載対象外でないかを「98_掲載対象外」シートで確認する。

## 10. トーナメント表

- 開催日・会場・開始時刻は **トーナメント表に必ず入れる**（前回同様）。
- 各試合のコードは「日付＋会場記号＋コート＋開始時刻」。読み方は
  `docs/jwc2026/02_トーナメント表の読み方.md` を参照。
- トーナメントの線・組合せの形は共有フォルダ「04_組み合わせ等」の公式最新版PDFが正。
  Excel版はその文字情報をデータ化したもの。

## 11. 入稿データの渡し方

- Excelで渡す。デザイナー様の作業単位に合わせ、**チーム紹介メンバー表はチームごとにシートを分ける**。
  - シート名は `M{整理番号}_{チーム名}`（男子）／`W{整理番号}_{チーム名}`（女子）。
  - 併せて全体を1枚にまとめた「01_全体データ」シート（1行1名）も同梱し、検索できるようにする。
  - 「00_目次」に掲載順・整理番号・選手数・シート名・素材の有無を並べる。
- 共有はGoogle Driveの共有フォルダ。メール添付はしない（版の取り違え防止のため）。
- 差し替えたときは、旧版を消さずに「差替指示.txt」を同梱して新版を明示する。
