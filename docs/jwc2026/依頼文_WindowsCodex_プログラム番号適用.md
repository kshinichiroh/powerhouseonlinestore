# 依頼文（Windows Codex 宛）JWC2026 プログラム番号の適用

作成: 2026-09-15 ／ 依頼者: 岸 慎一郎（兵庫県バスケットボール協会U15部会 広報部）

## 背景

ダイコロ株式会社・中森様より「トーナメントとメンバーの掲載番号が異なる」とのご指摘があった。
調査の結果、入稿用メンバー表の番号に **大会申込書の右上に手書きされた整理番号**
（TO担当が受付順に振った事務番号）をそのまま使っていたことが原因と判明した。
抽選結果とは無関係な番号で、127チーム中123件が不一致だった。

その回答として、番号付きのトーナメント表Excelが用意された。
**このExcelの番号をプログラム番号（誌面に印字する番号）として使用する**（岸さん決定）。


## 作業

### 手順1　入力Excelの構造を報告する（作業前に必ず）

`2026 jwc 兵庫県予選.xlsx` を開き、以下を報告してから次へ進む。**勝手に推測して進めない。**

- シート名の一覧
- 番号とチーム名がどの列・どの範囲にあるか
- 男子・女子の区別がどう表現されているか（シート別か、列か）
- 番号の範囲（男子・女子それぞれ何番から何番まで、欠番の有無）

### 手順2　番号とチーム名を抽出する

男女別に「番号 → チーム名」を抽出し、`data/program_numbers.csv` として書き出す。

```
男女,プログラム番号,チーム名（入力Excelの表記）
```

### 手順3　公式PDFの組合せ番号と突き合わせる（重要）

`data/number_crossref.csv` の「トーナメント組合せ番号」「トーナメント表の表記」と照合する。
チーム名の比較は、比較用にのみ次の正規化を行う（**表記そのものは書き換えない**）。

- NFKC正規化／半角・全角スペースの除去／アンダースコアの除去／英字の小文字化

期待する結果は **全127件一致**。

- 一致しない件があれば、**その場で止めて一覧を報告する。** 黙って上書きしない。
- 男子77・女子50の件数が合わない場合も同様に止めて報告する。

### 手順4　選手名簿のチーム名と突き合わせる

`members_master.csv` のチーム名（JBA帳票の登録名）と、手順2の名前を同じ正規化で突き合わせる。

- 一致するはずの件数は **125件**（男子75・女子50）。
- 一致しない2件は **棄権チーム**であることを確認する。
  - 男子 BAMBOO Shoot U15（女子は掲載対象）
  - 男子 A.C.T. BASKETBALL CLUB 2026（女子は掲載対象）
  - これ以外が不一致になった場合は止めて報告する。
- 表記が揺れている既知の3件は**同一チーム**として扱い、**誌面にはJBA登録名を印字**する。

  | トーナメント表の表記 | 誌面に印字する名称 |
  | --- | --- |
  | ゴッド ドア | ゴッドドア |
  | HyogoForce（女子32） | Hyogo Force |
  | BLACK PANTHERS_U14 | BLACK PANTHERS_U14 |

### 手順5　入稿用Excelを作り直す

`tools/build_xlsx.py` を改修して再生成する。

- メンバー表の各シート・目次に **プログラム番号**の列／欄を追加する。
- **チーム別シートはプログラム番号の順に並べ替える**（男子→女子）。
  シート名は `M{プログラム番号2桁}_{チーム名}` ／ `W{プログラム番号2桁}_{チーム名}`。
- 整理番号・掲載順は**事務用なので誌面には出さない**。参照用に目次へ残すのは可。
- トーナメント表データ版の「05_男子_組合せ」「06_女子_組合せ」の番号が
  プログラム番号と一致していることを確認する。
- 両ファイルの `99_制作ルール` シートに次の1行を追加する。
  「誌面の番号はプログラム番号（トーナメント表の番号）。整理番号・掲載順は事務用で誌面に出さない。」

### 手順6　検算（必須）

次をすべて確認し、数値を報告する。合わなければ止めて報告する。

| 項目 | 期待値 |
| --- | --- |
| トーナメント表の総数 | 127（男子77・女子50） |
| メンバー表の掲載チーム数 | 125（男子75・女子50） |
| 選手数 | 1,781名 |
| チーム別シート数 | 125 |
| プログラム番号の重複 | 0件（男女別に一意） |
| 番号なしのチーム | 0件 |

チーム別の選手数は、`全体検証版` xlsx の「チーム別進捗」シートの選手数と全件一致すること。

## 禁止事項

- 推測で埋めない。合わない箇所は**必ず止めて報告**する。
- チーム名を勝手に直さない。誌面表記はJBA登録名、比較は正規化のみ。
- **外部への送信・共有は一切行わない。** Google Driveの共有フォルダへ置くことも、
  ダイコロ様へメールすることも、**岸さんの明示承認を得るまで行わない。**
  共有フォルダへ置く行為は、通知前でも「入稿」とみなす。
- 選手個人データ（`members_master.csv` および生成物のxlsx）を**リポジトリにコミットしない**。
